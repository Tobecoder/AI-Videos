# 《AI 到底改变了什么？》一镜到底交互动画成片

基于 **Three.js (WebGL) + 高分 Canvas 2D + Web Audio API** 构建的 16:9 电影级一镜到底动态图形（Motion Graphics）短片。全片共 **6 幕 · 13 镜**，总时长 **`102.00 秒`（`60fps` 共 `6,120` 帧）**，支持首尾 `0.00px` 无缝无限循环。

- [分镜总案与音画设计（成片定稿版）](./storyboard.md)
- [三套视觉概念风格预览](./style-preview.html)

## 核心特性

1. **三阶段融合视觉演进**
   - **第一阶段（`S01–S06`，`00.00s – 45.20s`）**：深空三维景深 + 高锐度动态图形（4:1 气动超跑线框与十种海报裂变、180° 翻转 IDE 自愈编译、NLE 剃刀卡点与绿幕智能抠像、跨界曲速长廊推倒技术围墙、三维莫比乌斯全屏杰作）。
   - **第二阶段（`S07`，`45.20s – 54.40s`）**：配乐瞬间急刹断电，摄像机 **3 倍一镜急速拉远反差** 抽干色彩，揭露 21 张同质化克隆海报、5 台同步机械卡点 `♡ 0` 快剪手机与 `0 ACTIVE USERS` 空壳产品看板。
   - **第三阶段（`S08–S13`，`54.40s – 102.00s`）**：有机**手撕冷压水彩纸毛边**撕开 `60fps` 机械齿轮蓝图，切入 **`12fps` 抽帧炭铅笔手绘 + 湿画法暖橙水彩晕染**（手绘问号嫩芽、黄昏木质飞檐与玻璃风铃归鸟留白、逆流琥珀金线与灵感灯泡、风化沙砾 vs 鎏金金句、深空算力尾焰 + 手绘星盘船舵、灵魂火种闭环光标）。
2. **零外部依赖离线即开即播**
   - 直接双击打开 `index.html`（支持 `file://` 离线协议）即可自动流畅播放。
   - 全片 13 段微软 `zh-CN-YunxiNeural`（云希男声）口播及逐词时间戳已编码内嵌于 `voiceover-data.js`，并随时间轴自动触发三阶段原创合成配乐与侧链闪避（Sidechain Ducking）。

## 运行与交互说明

无需构建或安装依赖，直接在浏览器中打开 [`index.html`](./index.html)：

- **开启声音**：首次点击画面右上角提示条或画布任意位置，即可解锁 Web Audio 云希口播与电影配乐。
- **章节与逐帧检视**：
  - 点击底部 **① 奇点提问 — ⑬ 灵魂火种** 章节胶囊可直达任一分镜。
  - 快捷键：`Space` 播放/暂停，`←` / `→` 逐帧步进（`1/60s`），`F` 切换全屏沉浸观看。
  - 支持 URL 参数定位任意时刻帧（例如 `index.html?t=57.5`）。

## 重新合成配音（可选）

音频文件与内嵌语音包均已生成完毕。如需修改台词并重新合成 `audio/*.mp3` 与 `voiceover-data.js`（需联网环境与 Node.js 18+）：

```bash
node scripts/generate-yunxi-vo.js
```
